## Findings considered and rejected

- **Modify the CloudflareOS backend model-routing kernel**: rejected because
  `AiModelConfig.apiUrl` already selects a server-side endpoint; kernel changes
  would add review risk without changing the failing transport.
- **Run an untracked relay only on `ciddeploy`**: rejected because a manual host
  process is not reproducible, health-gated, tested, or durable across deploys
  and reboots.
- **Spawn the relay inside `cfos-run-local-wrapper.mjs`**: rejected because it
  couples failures and prevents independent PM2 health, restart, and logs.
- **Retry interrupted model streams automatically**: rejected because model
  requests are billable and non-idempotent; a retry can duplicate generations
  and tool actions.
- **Build a generic forward proxy**: rejected because accepting arbitrary
  origins or paths expands the credential-forwarding trust boundary beyond the
  one provider/endpoint proven necessary.
- **Add another TROM dashboard or report Gadget**: rejected because it would
  reproduce TROM presentation instead of enabling a continuing executive
  investigation in chat.
- **Put hypotheses, scores, cases, or director decisions in `gatekeeper-trom`**:
  rejected because the Gatekeeper is the factual read-only boundary; agent
  reasoning and longitudinal state belong to the chat and its approved Gadget.
- **Change TROM to support the first implementation pass**: rejected as an
  initial path because existing authenticated endpoints cover trend, detail,
  and open exposure. Their measured/default ambiguity is disclosed and remains
  a production-release gate rather than being hidden with a heuristic.
- **Add Workshop kernel/shared/frontend code for recurrence**: rejected because
  persistent `self` callbacks, user-created Gadgets, Gatekeeper bindings, and
  weekly Scheduler rules already provide the required primitives.
- **Ship a trained breach-probability model now**: rejected because test data
  cannot establish calibration, coverage, or enough breach examples; the
  shadow quarter first measures whether transparent warnings are useful.
